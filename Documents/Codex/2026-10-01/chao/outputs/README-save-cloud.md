# Sao lưu dữ liệu Vườn Nhỏ

Game chỉ lưu trên thiết bị bằng bộ nhớ trình duyệt. Dùng nút **⬇️ Xuất dữ liệu** để tải tệp JSON sao lưu xuống máy. Trên trình duyệt hoặc thiết bị khác, mở cùng phiên bản game và chọn **⬆️ Nhập dữ liệu** để khôi phục. Nhập bản sao lưu sẽ thay tiến độ đang có trên thiết bị sau khi bạn xác nhận.

Các tệp `supabase-setup.sql` và cấu hình cloud trước đây không còn được game sử dụng.
