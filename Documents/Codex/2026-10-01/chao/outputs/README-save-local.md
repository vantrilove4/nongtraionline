# Lưu dữ liệu trên thiết bị — Vườn Nhỏ

Game chỉ tự lưu tiến độ vào bộ nhớ trình duyệt trên thiết bị hiện tại.

- **⬇️ Xuất dữ liệu:** tải bản sao lưu JSON về máy. Nên xuất trước khi xóa dữ liệu trình duyệt hoặc chuyển thiết bị.
- **⬆️ Nhập dữ liệu:** chọn tệp JSON Vườn Nhỏ đã xuất trước đó để khôi phục. Game kiểm tra tệp và hỏi xác nhận vì thao tác này thay tiến độ đang lưu trên thiết bị.

Để chuyển tiến độ sang máy khác: xuất tệp trên máy cũ, chuyển tệp sang máy mới, mở game và nhập tệp ở đó. Mỗi trình duyệt/thiết bị có bản lưu riêng.
